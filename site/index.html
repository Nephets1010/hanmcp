hanmcp

Turn any documentation site into a working MCP server, in one command. Zero dependencies, no API keys, no embeddings, no cloud.

npx hanmcp https://docs.example.com/

Read the documentation · 中文文档

What it does

hanmcp crawls a documentation site, converts every page to clean markdown, builds a dependency-free search index, and writes out a standalone MCP server that Claude, Cursor, or any other MCP client can connect to. The output is three files you can copy to another machine: server.mjs, index.json and docs/.

It is built Chinese-first. Retrieval works on Chinese, Japanese and Korean text without a dictionary or a segmentation model, and non-ASCII path segments stay readable as filenames.
