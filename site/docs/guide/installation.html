Installation

hanmcp requires Node.js 20 or newer and nothing else. It has zero runtime dependencies, and a check in continuous integration fails the build if that ever stops being true. There is no compiler step, no native module to rebuild, and no post-install script.

Run it without installing

The fastest path is to invoke it directly. Nothing is written outside your current directory:

npx hanmcp https://docs.example.com/

Install it globally

If you build documentation indexes regularly, install it once. The package is a few hundred kilobytes and the global install is what most CI pipelines use:

npm install -g hanmcp
hanmcp --version

From source

Working on hanmcp itself, or pinning to a commit, both start the same way. The test suite needs no network access because it starts a documentation site on localhost and crawls that:

git clone https://github.com/Nephets1010/hanmcp
cd hanmcp
npm run check

Verify the install

A working install crawls the bundled sample site end to end and talks to the server it generates. This is the same command continuous integration runs on every commit, so if it passes on your machine your environment matches the supported one exactly:

npm run demo

Common problems

  • The process exits with an unsupported engine error: you are on Node 18 or older. hanmcp uses the built-in test runner and the global fetch API, both of which stabilised in Node 20.
  • npx downloads the package on every run: that is expected and intended for a one-off. Install globally to cache it.
  • The build finishes and the output directory is empty: the entry URL probably returned a redirect to a different origin, which the crawler deliberately refuses to follow across hosts.
