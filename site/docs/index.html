hanmcp

hanmcp turns a documentation site into a working MCP server in one command. It crawls the site, converts every page to clean markdown, builds a dependency-free search index, and writes out a standalone server that Claude, Cursor, or any other MCP client can connect to. There is no install step, no API key, no embedding model to download, and no cloud service in the loop.

Why it exists

Most documentation is invisible to an AI agent. The agent either cannot reach the site at all, or it fetches pages one at a time and burns context on navigation chrome. Existing tools that solve this assume an embedding provider and an API key, which rules out air-gapped machines, internal wikis behind a VPN, and anyone who does not want to ship their documentation to a third party.

hanmcp takes the opposite position. Retrieval over documentation is a solved problem that does not need a model. A local BM25 index over a few hundred pages costs a few megabytes, builds in seconds, and works offline forever.

Design constraints

Four constraints shaped every decision in this project: zero runtime dependencies, no network access after the crawl, correct behaviour on Chinese, Japanese and Korean text, and an output bundle small enough to commit to a repository. Anything that threatened one of those four was rejected regardless of how useful it looked.
