Orbital DB

Orbital DB is an embeddable time-series database that runs in under 8 MB of memory. It is built for edge devices, industrial gateways, and any deployment that cannot afford a cluster.

Why it exists

Every existing time-series database assumes a cluster somewhere. Orbital assumes a device. The entire storage engine lives in one file you can copy with scp, and a single writer handles 120,000 samples per second on a four-core gateway.

Design constraints

Three constraints shaped every decision in this project: total memory under 8 MB, no background compaction that can starve a real-time workload, and a write path that never blocks the caller for longer than one millisecond.
