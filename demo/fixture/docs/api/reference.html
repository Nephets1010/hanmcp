API reference

Orbital exposes one query language and three transport bindings. The language is SQL with duration literals and three extensions: GROUP BY time(), gap filling, and continuous queries.

Aggregates

The standard set is available: mean, sum, min, max, count, first, last, spread, and stddev. Percentiles are computed exactly rather than approximately, which is affordable because partitions are already sorted by time.

SELECT percentile(value, 0.99) FROM latency WHERE time > now() - 15m;

Gap filling

Time-bucketed queries return one row per bucket by default, including buckets with no data. Use fill(none) to drop empty buckets instead, or fill(previous) to carry the last known value forward.

SELECT mean(value) FROM temperature
WHERE time > now() - 6h GROUP BY time(1m) fill(previous);

Continuous queries

A continuous query materialises an aggregate as new data lands. It is the supported way to downsample old data before retention drops the raw samples.

CREATE CONTINUOUS QUERY hourly_temp ON telemetry
BEGIN
  SELECT mean(value) INTO temperature_hourly
  FROM temperature GROUP BY time(1h), site
END;
