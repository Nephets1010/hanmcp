Getting started

This guide takes you from an empty directory to a running database with data in it. It assumes a Linux or macOS host and does not require an account.

1. Install

Orbital ships as a single binary. There is no daemon to configure and no separate client.

curl -fsSL https://get.example.com/orbital | sh
orbital --version

2. Create a database file

A database is one file. Point Orbital at a path that does not exist yet and it will create it.

orbital init ./telemetry.odb --retention 30d

3. Write your first samples

The write path accepts line-delimited samples, which makes it easy to pipe from an existing collector.

orbital write ./telemetry.odb <<'EOF'
temperature,site=north value=21.4 1758000000
temperature,site=south value=23.9 1758000000
EOF

4. Query it back

Queries are plain SQL with duration literals. The engine only reads the partitions that overlap the time range.

SELECT mean(value) FROM temperature WHERE time > now() - 1h GROUP BY site;

Troubleshooting

If the process exits with EACCES, the directory holding the database file is not writable by the current user. If writes are slow, check whether the storage medium is a network filesystem: Orbital requires a local disk for its append-only log.
